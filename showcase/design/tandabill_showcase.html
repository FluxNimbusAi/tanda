Pattern sources

  • Phantom: balance-first home, one primary CTA, activity below the fold.
  • Solflare: every status chip = icon + label + color. Colorblind-safe by construction.
  • World ID: orb badge per seat — "everyone in this bill is a verified human" (grants endpoint: nullifier + verified_at).
  • Subtlety rule: the only glow on screen is the CTA. The big number is crisp, un-glowed.

State machine

bill → {expenses[], seats[], escrow, settlement?}
CTA = f(state):
  unfunded → "Fund escrow"
  funded, not initiated → "Initiate settlement"
  initiated, you unconfirmed → "Confirm settlement" ← this screen
  fully confirmed → "Execute settlement" (owner)
  executed, unclaimed → "Claim payout"

Pattern sources

  • Coinbase Wallet: transaction lifecycle as vertical timeline, one node per step, per-step status.
  • Node colors follow the semantic scale: mint = done, amber = waiting on you/them, blue = in flight, slate = refunded.

Pattern sources

  • World mini-apps: bottom tab nav, one task per page, CTA always visible, 100dvh + overscroll fix — review-gate compliance, not style.
  • Base app: card elevation on near-black, generous radius, confident minimal type.
  • Danger actions: ghost blue → red border on confirm. Destructive is never the default color.
  • Empty states are designed screens with product voice — they do the selling when the ledger is blank.

Technical elevation (v1 scope, beyond the visual pass)

  • Settlement state machine in the shell — UI = pure function of bill_index reads (/api/settlements, /settlements/<bill>, /api/grants, /bills/by-userop). No client-side address guessing (W8 law).
  • Debt minimization — greedy min-transfer view pre-settlement: "3 transfers settle this bill" with exact pairs. Splitwise's headline feature, client-side math over on-chain claims.
  • preferredCurrency-aware pay — MiniKit state gives it free; WLD / local stablecoin path alongside USDC.
  • Native growth loop — MiniKit.chat invite + share sheet: one tap puts the bill invite in World chat.
  • Nudge engine UI — six settlement triggers, hard caps, default-off; in-app toast + pending-notifications counter now, MiniKit notifications command when it ships.
  • Performance budget — initial ≤2–3s, action <1s, Eruda off in prod, EN/ES localization scaffold first.
